# Shivadharshini Singaravelan | Academic Portfolio

A fast, responsive academic website for a B.Sc Forensic Science student (Lovely Professional University), orator and MUN debater. Built with plain HTML, CSS and JavaScript, so it needs no build tools and runs directly on GitHub Pages.

**LinkedIn:** https://www.linkedin.com/in/shivadharshini-singaravelan-083872448

## Features
- Home, About, Education, Public Speaking & MUN, Event Management and Contact sections
- Events list with automatic Upcoming / Past filtering
- Light and dark mode (follows the device, with a manual toggle)
- Mobile-friendly layout and basic SEO tags

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page content and the events list |
| `style.css` | All styling and theme colours |
| `README.md` | This guide |

Keep `index.html` and `style.css` in the same folder.

## Publish on GitHub Pages
1. Create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css` and `README.md` (Add file > Upload files) and commit.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live in 1-2 minutes at `https://YOUR-USERNAME.github.io`.

## Customise
- **Events:** edit the `events` list near the bottom of `index.html`. Each event needs `title`, `date` (YYYY-MM-DD), `place` and `desc`.
- **Education:** add entries inside the `.timeline` block in `index.html`.
- **Colours:** change the variables at the top of `style.css` (`--accent`, `--accent2`, `--bg`).
- **Text:** replace the placeholder content (sample events, education timeline) with your real details.

## Updating the site
Open the file on GitHub, click the pencil icon, edit, and commit. The site refreshes automatically.
